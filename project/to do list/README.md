# To do list

Простой ежедневный планировщик задач. Чтобы начать, открой `index.html` в браузере.

## Что внутри

- Задачи добавляются для выбранного дня и сохраняются в локальном хранилище браузера.
- День можно сменить стрелками или вернуться к сегодняшнему дню.
- У задачи есть приоритет: «Срочно», «Второстепенно» или «Отложено на потом».
- Выполненные задачи отмечаются галочкой, а кольцо и полоса показывают долю завершённых дел.
- Название и приоритет задачи можно изменить, а задачу - удалить.
- Фильтр позволяет показывать все задачи, активные или выполненные.

Данные остаются в том браузере и на том устройстве, где ты открываешь страницу. Интернет для работы не нужен; он нужен только для загрузки шрифтов.
